# Skill: seg-error-topology
# 分割误差空间分布画像（error topography）

把逐体素误差（FP=过分割、FN=欠分割）投影到**GT 归一化相对坐标**上，回答调优中最常
问的定位问题：**误差发生在器官的哪个部位**——是头端还是足端、腹侧还是背侧、中心带
还是端部、端部之外外溢多少。输出群体级画像（分箱质量份额 + 局部漏检率 + 逐例 μ_r
分布），直接喂给下一轮配置决策（如"头端外溢主导 → 收紧头端边界损失权重 / 端部先验
后处理"）。

## 何时用（触发条件）

- 分割模型进入调优期，逐例指标（dice/HD95）已经看完，需要**空间归因**：误差集中在
  哪个方向、哪个相对深度；
- bad case 分析定位到"模型能力层"（见 badcase-analysis 五层定位），需要把个案印象
  升级为**群体级、可复现的分布规律**；
- 验证后处理/损失改动是否真的压掉了目标部位的误差（改动前后各跑一次画像，对比
  分箱份额与局部漏检率——同口径可对照）。

## 前置条件（缺则先在任务仓库补/确认）

1. **对齐的 pred/gt 二值掩码对**：同一网格、同形、同轴序（含方向与裁剪对齐——
   跨源掩码先做几何对齐并程序化核验体素数守恒）。掩码可来自任务仓库的推理管线
   （在线推理后直接传数组）或磁盘文件（nii/nrrd/npz）。
2. **spacing（mm，数组轴序）**：必须与掩码数组轴序一致；nii 轴序与数组轴序的关系
   任务仓库常做 transpose，**不做头文件猜测，一律显式传入**。
3. **轴的方向语义**：哪个数组轴对应头-足/腹-背/左-右、索引增大指向哪端——由任务
   仓库从影像几何（方向矩阵符号）**程序化核验**后给定（本技能不做影像判读；方向
   标签写错则结论整体翻转，故必须在任务仓库有一次性核验记录）。
4. GT 非空（相对坐标以 GT 沿轴范围为基准；GT 空的例跳过并如实计数）。

## 口径定义（脚本内强制一致）

- **相对坐标 r**：GT 沿轴体素范围 [v_min, v_max] → 中心 c、半长 h（<0.5 体素按
  0.5 护底），r=(v−c)/h。GT 内部 |r|≤1；FP 可越界（|r|>1 = 沿该轴溢出 GT 实际
  范围，与"距 GT 表面距离"互补：前者定位沿轴向哪端，后者刻画贴近程度）。
- **分箱**：10 箱（[−∞,−1) 与 [1,+∞) 为轴向外溢箱，内侧 8 箱每 0.25 一箱）。
  FN 只落内侧箱；每箱计 FN/FP/GT 质量（ml）。
- **局部漏检率**：内侧逐箱 FN/GT——该相对深度处标注体素被漏掉的比例，与全局漏检率
  （总体 FN/GT）直接可比，高者为富集区。FP 侧对应看分箱份额（FP 无"分母"可归一，
  以份额 + 外溢质量刻画）。
- **μ_r**：单例 FP（或 FN）质量加权平均相对坐标，符号直接给偏向（须配方向语义
  解读）；群体报中位数与四分位、以及与 dice 的 Spearman 相关。

## 聚合纪律（两口径并报，结论以逐例平均为主）

- **逐例平均（primary）**：每例误差先归一为份额再跨例平均——防个别大误差病例
  淹没群体规律；参与平均须过最小误差体量门槛（默认 0.05ml，`--min-err-ml`），
  排除数如实写入 summary；
- **汇总体（pooled）**：全部误差体素直接累加——反映误差质量的真实落点；
  两口径背离时（如 pooled 头端尖峰来自 2 例）必须回逐例确认是不是少数例驱动；
- 逐例 μ_r 的四分位区间跨 0 时不得宣称"群体偏向某端"，只报"例间分歧大"。

## 输出与解读规范

- `per_case.jsonl` / `summary.json` / `profiles.png`（每轴 FN/FP 份额 + GT 质量基线
  + 局部漏检率）/ `overview.png`（μ_r 与 dice 关系）；图内文字一律 ASCII，中文
  结论写报告；
- 报告句式示例：「z 轴 μ_r(FP) 中位 +0.31（偏向头侧），头端 0.25 区间（r∈[0.75,1)）
  局部漏检率 41% vs 全局 23%，头端外溢箱占 FP 质量 12%——头端边界同时存在漏检与
  外溢，指向……」。结论只引用程序化测量数值；
- **可视化红线不变**：本技能纯掩码测量，不渲染影像、不做视觉判读；若需逐例影像
  佐证，转 badcase-analysis 的渲染→用户审片流程。

## 与相邻技能/方法的边界

- **badcase-analysis**：逐例根因定位（标注/管线/预处理/模型/评测五层）与交付打包；
  本技能不定位根因、不打包，只给群体级空间分布画像。常见配合：badcase 定位到
  模型层 → 本技能刻画该模型误差的空间结构 → 结论进 next-config-recommendation。
- **label-ceiling-diagnosis**：测标注噪声压低的天花板（静态量化）；本技能测当前
  模型误差的空间落点，二者结合可区分"端部标注口径松"与"模型端部能力弱"。
- **error_decomposition 型逐例脚本**（任务仓库自建，如按距表面距离分带）：与本技能
  的轴向相对坐标正交互补——分带刻画"贴边界 vs 深部"，本技能刻画"哪一端/哪一侧"。

## 脚本

- `scripts/error_topography.py`：CLI（`--pairs` 配对清单）+ 函数级 API
  （`compute_case` / `aggregate` / `plot_profiles`，供任务仓库在线推理包装脚本
  import，免去掩码落盘）。依赖：numpy / scipy / matplotlib（+nibabel/pynrrd
  按文件格式）。

```bash
python3 skills/seg-error-topology/scripts/error_topography.py \
  --pairs pairs.json --out runs/error_topography \
  --axis-names z,y,x \
  --axis-labels "z:+S/-I;y:+P/-A;x:+L/-R" --min-err-ml 0.05
```

## 已知陷阱

- **稀疏层面式标注（Slicer 描层 GT）会把层间体积全部误计为 FP**：分析前必须
  程序化核验 GT 的轴向占位密度（有前景的层数 / z 范围层数）。实测案例
  （thymic_seg 离线评估集，2026-10-14）：71 层 z 范围只标 8 层，稠密预测逐体素
  比对后 FP 占误差 98.5%、pred/GT 达 4~20 倍、dice 0.13——几乎全是表示口径差
  而非模型误差。稀疏时改三口径：贴层（标注层面上的平面内比对，画像主口径）、
  层间（范围内非标注层的预测体量，只量化不判对错）、越界（范围外延伸）；
- **方向标签写反 → 结论整体翻转**：方向语义必须来自任务仓库的几何核验记录，
  不许凭记忆/惯例填；
- 单平面薄片目标（GT 沿轴仅 1-2 体素）：半长护底后 r 会被放大到 ±1 附近，该轴
  画像退化为"两端箱"，解读时注明 GT 轴向厚度中位数；
- 逐例平均与汇总体背离时先查是否少数大误差例驱动（看 per_case 的 fn_ml/fp_ml
  排序头部）；
- μ_r 分母为空的例（该例无 FP/FN）自动记 None，不进分位数统计——summary 里的
  n 字段是有效例数，不是总例数；
- 掩码 dtype 陷阱：uint8 掩码参与布尔运算会走整数索引广播（曾致 +36GB OOM），
  脚本入口统一 `>0` 转 bool，任务仓库自建包装也要照做；
- 分箱边界口径：r=±1.0（GT 沿轴最端体素的精确值）归内侧端箱，外溢箱只收
  严格越界（|r|>1）体素——脚本已内置，自建重实现时注意 np.digitize 的半开
  区间会把 r=1.0 推进外溢箱。
