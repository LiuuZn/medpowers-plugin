# assets/preprocessing — 任务无关的预处理方法

本仓库的"数据处理"专指**预处理**（训练前的数据变换），任务无关。一条 = 一个方法卡（一个 md 文件），命名按方法名（如 `windowing-ct.md`、`resample-isotropic.md`）。

> 条目含代码（`<slug>.py`）时，代码须遵循统一代码规范 [../CODE_STYLE.md](../CODE_STYLE.md)（依赖、自包含、文件头、类型标注、数值稳定、自测块、与资产卡同名配对）。

## 方法卡字段

- **论文支撑（必填）**：按文末统一四问格式，简体中文写明
- **动机**：解决什么问题（强度尺度不一 / 冗余切片 / 各向异性 spacing 等）
- **适用**：模态（CT/MRI）、2D/3D、数据量级
- **参数与经验值**：典型取值、越界后果
- **实现参考**：兄弟项目中的落点（如 `/ssd/lx` 旧流水 `prepro_0_norm → prepro_1_crop3D → prepro_2_resample3_2D`）
- **坑**：插值对标签的影响、窗宽窗界丢失、裁剪漏目标等
- **实验反链**：相关 `EXP-*` 记录

## 收录边界

只写方法本身；某任务用哪套组合、为何选它，写进实验记录。

## 论文支撑统一四问（每项一两句话，写简单）

- **哪篇论文用了它**：团队/作者 + 简称 + 年份（附链接）
- **目的**：论文用它来解决什么问题
- **效果**：取得了什么提升（有数字写数字）
- **结论**：论文下的结论 / 适用边界

无论文支撑的方法不作为正式条目，先记入"补录起点"。
