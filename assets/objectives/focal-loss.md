# focal-loss（焦点损失）

**类别标签**：`[loss]`（可导损失）

## 论文支撑（统一四问）

- **哪篇论文用了它**：Lin, Goyal, Girshick, He & Dollár（FAIR），《Focal Loss for Dense Object Detection》（使用该损失的模型叫 RetinaNet），ICCV 2017，https://arxiv.org/abs/1708.02002 （本条目所读版本：arXiv v2 全文，即 ICCV 版——abs 页与 ar5iv HTML 渲染对照通读；公式编号依该版，式 (4) 为 focal loss、式 (5) 为 α 平衡版）。
- **目的**：单阶段密集检测训练时每张图要枚举约 10 万个候选位置（~100k locations），其中绝大多数是易分类背景，其损失总量淹没少数难例、训练低效甚至退化；focal loss 对标准交叉熵乘以 (1-p_t)^γ 因子，压低易分类样本的贡献，把训练聚焦到稀疏的难样本上。
- **效果**：同一 ResNet-50-FPN 网络，α-balanced CE 31.1 AP → focal loss 34.0 AP（+2.9 AP；表 1b 消融最优 γ=2、α=0.25）。对比最优 OHEM（32.8 AP），focal loss 用 ResNet-101-FPN 达 36.0 AP，领先 3.2 AP（表 1d）。最终模型 COCO test-dev 40.8 AP（ResNeXt-32x8d-101-FPN，§5.3 正文全称；表 2 简写作 ResNeXt-101-FPN）。
- **结论**：focal loss 能防止海量易分背景淹没检测器，是类别极不平衡训练的标准手段；γ=0 退化为 CE；结果对 γ∈[0.5,5] 相对稳健，α 需随 γ 增大而调小（γ=2 配 α=0.25 最优）。

## 形式

以未过 sigmoid 的 logits 为 x、标签 y∈{0,1}（编号依 arXiv v2 / ICCV 版）：

- 式 (2)：`p_t = p`（y=1 时）或 `1-p`（y=0 时），其中 `p = σ(x)`；随后正文句给出 `CE(p_t) = -log(p_t)`
- 式 (4)：`FL(p_t) = -(1-p_t)^γ · log(p_t)`，γ≥0 为 focusing parameter
- 式 (5)（论文实验采用的形式）：`FL(p_t) = -α_t · (1-p_t)^γ · log(p_t)`，其中 `α_t = α`（y=1）或 `1-α`（y=0），α 即式 (3) α-平衡 CE 中的权重

参考实现：同目录 `focal-loss.py`（sigmoid 二分类/多标签版 + softmax 多类版）。

## 适用

- 分割/分类/检测中**类别极不平衡**场景：正负样本比悬殊、易分背景占绝对多数。
- 密集预测天然同构的医疗场景：小病灶/结节/息肉检测、病灶体素占比极低的分割、逐像素分类。
- 通用 CV 出身，但"密集候选 + 极不平衡"结构与医疗影像病灶/小目标检测同构，已被广泛采用——如 3D 医疗目标检测框架 nnDetection（Baumgartner et al., MICCAI 2021）即以 RetinaNet 式架构 + focal loss 作为默认配置。

## 行为特征

- 降权量化（论文 §3.2 原文数字）：γ=2 时，p_t=0.9 的样本损失比 CE 低 **100 倍**，p_t≈0.968 低 **1000 倍**；错分样本（p_t≤0.5）损失至多被压到 1/4——易分样本近乎归零、难例主导更新。
- 训练早期即抑制海量易分负样本的梯度噪声，难例（小病灶边缘、低对比度区域）的信号相对放大。
- 损失数值被 (1-p_t)^γ 整体压缩，**不能与 CE 的损失曲线直接比大小**；应与 AP、sensitivity/PPV、Dice 等评价指标配合观察。
- 收敛中后期绝大多数样本梯度≈0，有效梯度集中在少数难例——梯度天然偏稀疏（见"坑"）。

## 调参经验

- 起步 γ=2、α=0.25（论文表 1b 最优组合）；γ∈[0.5,5] 一般稳健。
- **α 与 γ 耦合**：γ 增大时最优 α 减小（表 1b 规律），否则正样本被过度加权；两者要一起扫，单动一个容易得出"无效"结论。
- α=0.25 意味着正类只占 1/4 权重——与直觉相反，原因是 focal 因子已压掉大量易分负样本。
- 分割中常与 Dice 类损失组合（focal 管难例聚焦与类别不平衡，Dice 管整体重叠与边界）；组合权重属经验起点，非论文结论。
- 换用 focal loss 时保持归一化口径一致，否则有效学习率变了，对比失真。论文 §4.1 的训练口径是对全部 ~10 万 anchor 的 focal loss 求和后，按"分配到 ground-truth 框的 anchor 数"归一化（而非全部 anchor 数，因为多数是易分负样本）；`focal-loss.py` 的 `reduction="mean"` 是全元素均值，复现检测训练时需自行按正样本数归一化。

## 坑

- **梯度稀疏/训练停滞**：γ 偏大且模型已较准时，几乎所有样本梯度≈0，训练看似进入"收敛平台"；诊断时先降 γ 再怀疑 lr。
- **损失曲线误读**：focal loss 数值天然低于 CE，且随训练下降更快（易分样本被持续降权），跨损失函数比较曲线幅度没有意义。
- **概率不再校准**：focal loss 优化的不是朴素 CE 的置信分布，sigmoid/softmax 输出不能直接按概率解释；评测阈值需重新搜索。
- 多类分割用 softmax 版时，是把式 (4) 的 p_t 换成 softmax 概率的**常见推广，非论文原式**（论文为 sigmoid one-vs-all）；ignore 区务必排除在均值之外。
