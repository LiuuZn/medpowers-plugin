# unified-focal-loss —— 统一 Focal 损失（对称 UFL / 非对称 A-UFL）

## 论文支撑（统一四问）

- **哪篇论文用了它**：Michael Yeung, Evis Sala, Carola-Bibiane Schönlieb, Leonardo Rundo，《Unified Focal loss: Generalising Dice and cross entropy-based losses to handle class imbalanced medical image segmentation》，Computerized Medical Imaging and Graphics 95:102026, 2022，https://doi.org/10.1016/j.compmedimag.2021.102026 （预印本 arXiv:2102.04525，PMC 全文 PMC8785124）。本卡依据 arXiv v4 LaTeX 全文（2021-11-24 提交）通读整理，并与 PMC 已出版全文（公式编号一致）交叉核对。
- **目的**：医学分割的类别不平衡是双重的——输出不平衡（病灶体积远小于背景）与输入不平衡（单个 batch 内前景体素稀少）；CE 族损失只对输入不平衡稳健、Dice 族只对输出不平衡稳健。论文把两族损失统一到一个分层框架：δ 统一控制前景/背景权重（输出不平衡）、γ 统一控制 focal 难例聚焦（输入不平衡）、λ 控制两分量配比，把此前六个超参的搜索空间压缩到三个（实践上只调 γ）。
- **效果**：5 个公开不平衡数据集、对比 6 种 Dice/CE 族损失，非对称变体 DSC 全面第一：CVC-ClinicDB 0.909±0.023、DRIVE 0.803±0.006、BUS2017 0.824±0.063（2D 二类）；BraTS20 0.787±0.049（3D 二类，vs 次优 Focal Tversky 0.747±0.052）；KiTS19 肿瘤 0.634±0.079（3D 多类，vs Dice 0.536±0.074、Combo 0.554±0.081）、肾脏 0.943±0.011。全部显著优于基线（如 KiTS19 肿瘤 vs Dice p<0.05）。
- **结论**：此前所有 Dice/CE 族损失都是本框架的特例——γ=0、δ=0.5 时 λ=1 退化为 CE、λ=0 退化为 Dice；推荐固定 λ=0.5、δ=0.6、只调 γ（2D 在 [0.1,0.9] 网格搜、3D 直接取 0.5），γ=0.9 最差、0.5 最稳；非对称变体整体略优于对称。边界：未含边界类（boundary-based）损失对比、未在 nnU-Net 级强基线上验证、多类共享单个 γ 非最优（作者自述）。

## 类别标签

`[loss]`（可导损失；梯度由框架自动微分，论文不提供解析梯度）

## 形式

修正 Tversky 指数（论文式(18)，对每个类 c 一对一 vs rest）：

```
mTI_c = Σᵢ p0ᵢg0ᵢ / ( Σᵢ p0ᵢg0ᵢ + δ·Σᵢ p0ᵢg1ᵢ + (1−δ)·Σᵢ p1ᵢg0ᵢ )
```

修正 Focal 损失（论文式(16)，逐体素、逐类权重 w：前景 δ、背景 1−δ）与修正 Focal Tversky 损失（论文式(17)）：

```
L_mF  = (1/N) Σᵢ Σ_c w_c·(1−p_t,c)^γ·(−log p_t,c)
L_mFT = mean_c (1−mTI_c)^(1−γ)
```

对称 UFL（论文式(19)）与非对称 A-UFL（论文式(20)-(22)）：

```
L_sUF = λ·L_mF + (1−λ)·L_mFT
L_maF : 前景（稀有）类去 focal（只乘 δ），背景保留 (1−p)^γ 抑制
L_maFT: 背景去 focal（取 1−mTI_0），前景保留 (1−mTI)^(1−γ) 增强
L_aUF = λ·L_maF + (1−λ)·L_maFT
```

**参数语义**：δ 是前景类权重（背景 1−δ），同时在 mTI 中 δ 加权假阴 FN、(1−δ) 加权假阳 FP；γ∈[0,1] 同时控制 mF 的难例抑制强度与 mFT 的难例增强强度（指数 1−γ），γ=0 时两组件同时退化为加权 CE / 加权 Tversky。注意：论文排版式(16)(17)把两个 focal 指数印反了（mF 印成 (1−p)^(1−γ)、mFT 印成 (1−mTI)^γ），与其正文特例声明矛盾，应以正文与官方代码为准（见"坑"与参考实现文件头不一致处第 1 条）。

## 适用

- 分割（论文场景：2D 二类 CVC-ClinicDB/DRIVE/BUS2017、3D 二类 BraTS20、3D 多类 KiTS19）；为前景极不平衡的医学目标设计。
- 想要"一个损失覆盖 CE/Dice 族超参空间"的场景：不必再在 CE、Dice、Focal、Tversky、Focal Tversky、Combo 之间试错，退化关系保证框架包含它们。
- 输入不平衡（batch 内前景稀少）与输出不平衡（前景体素占比小）并存的训练；两者分别由 γ 与 δ 应对。
- 前景极稀有、怕 focal 压低前景信号时选非对称变体（论文表现最好的变体）；前景/背景均衡或前景不算稀有时可先试对称变体。

## 行为特征

- 双分量结构：逐体素 CE 分量（分布级，早期塑形信号密）+ 逐区域 Tversky 分量（区域级，与 Dice 指标同向），λ=0.5 时齐头并进；训练时 DSC 曲线通常比纯 CE 族收敛更快、比纯 Dice 族早期更稳。
- γ 在两组件方向相反：mF 的 (1−p)^γ 压低易例、防止海量背景主导梯度；mFT 的 (1−mTI)^(1−γ) 反而在收敛后期（mTI→1）维持较高损失、防止过早平台——这正是论文认为 λ 部分冗余、固定 0.5 的原因。
- δ↑ → 召回升、精确度微降（显式 precision-recall 旋钮）；论文取 δ=0.6（低于 Tversky 常用的 0.7），因为 CE 分量已带前景偏置。KiTS19 肿瘤 DSC 0.336→0.634 主要来自 recall 0.303→0.695。
- γ 鲁棒性好：[0.1,0.9] 全程稳定优于基线，0.9 最差、0.5 附近最稳（论文 Fig.3）；超参敏感性低是相对 Focal/Focal Tversky 的主要工程优势。
- 观察指标：DSC/IoU 配 precision/recall 双轴（确认 δ 方向效应出现：A-UFL 的 recall 应系统性高于 Dice 基线）；损失曲线注意两分量的相对走势（λ 各 0.5 可分开记录 L_mF、L_mFT 辅助诊断）。

## 调参经验

- 论文默认（直接起步）：**λ=0.5、δ=0.6、只调 γ**；2D 在 [0.1,0.9] 网格搜、3D 直接 γ=0.5。第一轮就按 (0.5, 0.6, 0.5) 跑基线。
- γ 只在 [0,1] 内取：γ>1 会让 mFT 指数 1−γ 变负（易例损失被放大、完美预测附近发散），不在论文定义域；γ=0 是合法诊断点——等于"加权 CE+加权 Tversky"组合损失，可用来隔离 focal 的贡献。
- δ 方向调节：漏检多（低召回）→ δ 提到 0.7；误报失控 → 回调 0.5~0.55。CE 分量与 mTI 的 FN/FP 权重被 δ 同时联动，一次只动 δ。
- 2×RTX 4090（约 23 GB/卡）预算：AMP 训练建议 from_logits 入口（log_softmax 稳定路径）避免 fp16 下 sigmoid/softmax 饱和后取 log 发散；mTI 的软计数累加保持 fp32（sum 前转 float）；损失量级 O(0.1~1)，与常见 CE+Dice 组合同量级，无需额外缩放。
- 调参顺序建议：默认基线 → 看 precision/recall 方向调 δ → 依欠拟合/过拟合微调 γ（难例欠拟合升 γ、后期噪声敏感降 γ）→ λ 不动。每轮按实验记录规范记录。

## 坑

- **论文排版公式指数印反**：式(16)(17)的 focal 指数（mF 印成 1−γ、mFT 印成 γ）与论文正文自己的特例声明（γ=0、δ=0.5 时退化 CE/Dice）矛盾；官方两份代码（mlyg、MONAI）均按 mF 指数 γ、mFT 指数 1−γ 实现。读论文按正文，接实现先跑退化检查（参考实现自测第 6/7/8 项）。
- **λ 分配三个来源不一致**：论文式(19)(22)与 MONAI 为 λ·FL+(1−λ)·FTL；mlyg 官方 Keras 仓库为 weight·FTL+(1−weight)·FL。默认 λ=0.5 时数值相同，λ≠0.5 时必须核对所用实现的约定方向。
- **MONAI 的 FL 分量口径减半**：MONAI `AsymmetricFocalLoss` 把逐体素的两类损失堆叠后直接 mean（类维参与平均），其 Focal 分量 = 官方 Keras/论文口径的一半；混用两家的损失曲线/学习率不可直接比较（对拍证据见参考实现文件头不一致处第 8 条）。
- 官方代码只支持二类：mlyg Keras 版逐类索引硬编码 `[...,0]/[...,1]` 且 3D 索引实际有误（仅 2D 正确）；MONAI 文档写明 binary-only（其 docstring 说输入是 logits 但前向并不做 sigmoid，实际收概率）。多类需按论文 Σ_c 形式自行推广（参考实现已做：通道 0=背景、全部前景类视为稀有类，与论文 KiTS19 实验口径一致）。
- 多类共享单个 γ 次优：前景各类频率差异大时（如 KiTS19 肾:肿瘤≈4:1）逐类 γ 可能更好，但论文未验证（作者自述局限）；按此扩展属无直接论文支撑的尝试，需实验记录。
- 未在 nnU-Net 级强基线验证：论文对比配置均取各自原文献设置；在重增强、强流水线下增益可能缩水，引入前先与现有组合损失（如 CE+Dice）做同条件对比。
- 数值两点：官方 FTL 写成 (1−TI)·(1−TI)^(−γ)，完美预测（1−TI→0）时负指数上溢 inf；应改等价的 (1−TI)^(1−γ)（参考实现即此写法）。fp16 下概率饱和到 0/1 再取 log 得 −inf，需概率 clip（ε=1e-7）或 logits 入口。
