# boundary-dou-loss —— 边界差集并集比损失（Boundary DoU Loss）

## 论文支撑（统一四问）

- **哪篇论文用了它**：Fan Sun、Zhiming Luo、Shaozi Li（厦门大学），《Boundary Difference Over Union Loss For Medical Image Segmentation》，MICCAI 2023（Springer LNCS，DOI 10.1007/978-3-031-43901-8_28），https://arxiv.org/abs/2308.00220 ；官方代码 https://github.com/sunfan-bvb/BoundaryDoULoss 。本卡依据 arXiv v1（2023-08-01，ar5iv 全文）通读整理。注意作者为 Sun/Luo/Li——网上常见误记"Wang"系与其它边界损失文献混淆。
- **目的**：现有分割损失大多只关注整体区域，少数边界损失（如 surface loss）需要与其它损失组合使用且收益不稳。论文受 Boundary IoU 启发，把 Dice 改写为预测与真值"差集"占优的比值形式，对边界不吻合部分（差集 S_D）加权，用**单一损失**即可引导边界区域分割；并按目标尺寸自适应调整加在边界上的注意力（α），只依赖区域计算、无距离变换。
- **效果**（论文表 1-3）：Synapse 上 Swin-UNet 相比 Dice+CE 基线 DSC 78.30→79.87、HD 24.71±2.84→**19.80±2.34 mm**、Boundary IoU 86.72→87.78（相比纯 Dice 基线 77.98 为 +1.89）；UNet 76.77→78.68、TransUNet 78.19→79.53。ACDC 上 Swin-UNet DSC 90.17→91.02、UNet 90.17→90.84、TransUNet 90.69→91.29。分桶统计：六个（模型×数据集）组合中**小目标桶增益均大于大目标桶**（如 Synapse/UNet 大 +2.29、小 +2.46；Synapse/Swin-UNet 大 +1.86、小 +2.41；ACDC/UNet 大 +1.13、小 +1.93）。
- **结论**：Boundary DoU Loss 仅靠区域计算即可引导边界分割，单损失使用、训练稳定，在 UNet/TransUNet/Swin-UNet × ACDC/Synapse 一致有效；目标越小（边界占比 C/S 越高）收益越大。适用边界：论文实验为 2D 切片多类分割（ACDC 心脏、Synapse 腹部器官）；α 截断 0.8 出自官方代码而非论文；3D 体输入未被论文验证（本仓库参考实现做了自然扩展）。

## 类别标签

`[loss]`（可导损失；全式为区域软计数的比值，梯度由框架自动微分，论文无解析梯度需求）

## 形式

论文定义（正文无编号公式，按 ar5iv 全文 Methodology 节；P=预测、G=真值）：

```
L_DoU = ( G∪P − G∩P ) / ( G∪P − α·G∩P )
```

记差集面积 S_D = |G∪P| − |G∩P|、交集 S_I = |G∩P|，即论文给出的等价改写：

```
L_DoU = S_D / ( S_D + (1−α)·S_I )
```

softmax 输出下的可导训练形式（官方实现口径，硬 mask 下与集合基数严格相等）：

```
loss = ( Σp² + Σg² − 2Σp·g + s ) / ( Σp² + Σg² − (1+α)·Σp·g + s )
```

其中 s=1e-5 平滑；"部分交集"计入比例 w = 1−α：**w=2 时严格退回 Dice 距离 S_D/(S_D+2S_I)（即论文所写 L_Dice = 1 − 2S_I/(2S_I+S_D)）、w=1 时为 IoU loss（Jaccard 距离）、w→0 退化为纯边界（恒 ≈1）**。

α 按目标尺寸自适应（论文原文）：

```
α = 1 − 2×(C/S) ,  α ∈ [0,1)
```

C 为目标边界长度（官方口径：3×3 十字邻域零填充卷积，数"在目标内但 4 邻域+自身计数 ≠ 5"的像素）、S 为目标面积；大目标判据 C/S < 0.2。C/S 越小（目标越大越紧致）α 越大、边界注意力越强；官方代码再截断 min(α, 0.8)（论文无截断）。

## 适用

- 多类 MRI/CT 分割中希望改善边界质量（HD/Boundary IoU）的场景；论文主打**单一损失即可**，无需与 CE 组合、无需距离图。
- 想"给边界加注意力"但不想引入距离变换（surface loss 类）或形态学后处理（Boundary IoU 类）的 3D 场景——纯区域池化/卷积计算，GPU 上零额外开销。
- 小目标、边界占比高的目标（C/S ≥ 0.2 的桶收益更大，见统一四问"效果"）。
- 极度细长的管状/丝状目标（C/S ≈ 1）不受益：α 自适应滑向 −1 后完全退回 Dice，需配合第 3 条或手动固定 α。

## 行为特征

- 与 Dice 同族的区域级目标（不看 TN、无逐像素权重图），收敛动力学接近 Dice，可直接替换 Dice loss 跑基线对比。
- 自适应 α 让损失在"边界注意力"与"区域 Dice"之间滑动：大目标（C/S<0.1 时）α 截到 0.8、交集只按 20% 计入分母，差集主导；小目标自动滑向 Dice 语义保住区域梯度——这是"小目标分桶收益反而大"的机制来源。
- HD 类边界指标的改善比 DSC 更明显（Synapse Swin-UNet：DSC +1.57、HD −4.91 mm）；DSC 已接近上限、HD 已很小时（ACDC HD≈1.3 mm）收益趋零。
- 观察指标：DSC、HD95、Boundary IoU（论文用这三个）；可对照本仓库 `/ssd/lx/metrics/metrics.py` 的 hard Dice 与 HD 类指标，训练时盯 DSC↔HD 是否同步改善（只涨 DSC 不降 HD 说明边界增益未兑现）。

## 调参经验

- 默认直接用官方口径：自适应 α + 截断 0.8（本实现默认即此）。截断值来自官方代码注释："推荐 0.8 截断，部分数据集更好、其余影响很小"；设 α 上界为 1.0 即复原论文无截断版本。
- 固定 α 模式（adaptive=False）用作消融：α=−1 ≡ Dice（保守起点）、α=0 ≡ IoU loss、调大（≤0.8）边界注意力增强；论文场景无需人工调 α。
- 口径对齐清单（复现/对比实验必查）：输入 logits+softmax、含背景类逐类计算、**每类整批求和成单比值再类平均**（官方聚合口径）、平滑 1e-5 加在分子/分母/α 计数三处。
- 2×RTX 4090（约 23 GB/卡）预算：损失本身无显存开销，AMP 训练时软计数累加建议 fp32（同 tversky-loss.md 的建议），α 的边界计数是 0/1 整数卷积、半精度下也精确。
- 想给细长目标加边界权重时，可手动固定 α（如 0.5）覆盖自适应值，但需自行验证（无论文依据）。

## 坑

- **α 的两个约定极易弄反**：论文 α（本卡口径）越大边界注意力越强、**α=−1 才是 Dice**；部分转述/实现把它写成"部分交集权重"（=1−α，即本卡 w）方向相反。接手他人实现先做方向对拍（参考实现自测第 4 项）。
- **聚合口径**：官方是"每类整批求和成单比值再类平均"，逐样本口径数值不等（mean(比值) ≠ 比值(总和)）；对比实验必须统一，本实现默认官方口径。
- 0.8 截断与 1e-5 平滑都是官方代码细节、论文未写；论文表内数字依赖这些细节，纯按论文式复现会有小偏差。
- 边界带是"十字邻域不满员"的纯区域定义，**不是** Boundary IoU 的形态学膨胀带——论文引用的"对角线 0.5%"（Boundary IoU 定义，Cheng et al.）与官方评测脚本的 dilation_ratio=0.02 都只属于评测指标，与损失计算无关，勿混入实现。
- 零填充卷积数边界：贴图像边界的区域边界带偏大、α 偏小（向 Dice 滑）——patch/裁剪策略会间接影响 α。
- 空类（真值全空）loss 恒为 1、梯度 0（官方口径）：训练早期某类从未出现时不提供该类梯度信号。
- 较新的独立第三方复现少，跨架构/跨模态收益建议先在自家数据上以 Dice 基线对照验证；HD 已很小的任务（ACDC 量级）增益有限。
- 官方实现仅 2D；3D 为本仓库参考实现的扩展（六邻域十字卷积），论文未验证 3D 体输入。
