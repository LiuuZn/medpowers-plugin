# tversky-loss —— Tversky 损失函数

## 论文支撑（统一四问）

- **哪篇论文用了它**：Seyed Sadegh Mohseni Salehi、Deniz Erdogmus、Ali Gholipour，《Tversky loss function for image segmentation using 3D fully convolutional deep networks》，MICCAI 2017 MLMI workshop（Springer LNCS 10541, pp. 379–387），https://arxiv.org/abs/1706.05721 。本卡依据 arXiv v1 全文（2017-06-18）通读整理。
- **目的**：MS 病灶 MRI 分割中非病灶体素超过病灶 500 倍以上，Dice loss 是精确率与召回率的调和平均、对假阳/假阴等权，训练出的网络偏向高精确、低召回（漏检）；而临床中假阴性比假阳性更不可接受。论文以 Tversky 指数为损失，用 α/β 显式惩罚 FP/FN，让训练可以按临床偏好调整 precision-recall 平衡。
- **效果**：15 例 T1/T2/FLAIR MRI、二折交叉验证，(α,β)=(0.3,0.7) 相比 Dice loss（α=β=0.5）：DSC 53.42%→56.42%（约 +3）、F2 51.77%→57.32%（约 +5.5）、PR 曲线下面积 APR 52.57%→56.04%（约 +3.5）；敏感度随 β 单调上升（49.85%→65.57%）、特异度仅微降（99.93%→99.87%）；在低病灶密度病例上，Dice 网络完全漏检、β=0.7 网络成功检出。
- **结论**：Tversky 指数是 Dice（α=β=0.5）、Tanimoto 系数（α=β=1）、F_β 分数族（α+β=1）的统一广义框架；即使刻意偏向召回（β=0.7），综合指标也全面优于 Dice loss，说明泛化能力提升。属概念验证研究：仅 15 人数据、未与当时 SOTA 方法直接对比，作者明确指出需在更大标准数据集与多类任务上进一步验证。

## 类别标签

`[loss]`（可导损失；梯度可自动微分，论文式(4)(5)给出了解析梯度，实现中直接用框架自动微分）

## 形式

Tversky 指数（论文式(2)）：

```
S(P,G; α,β) = |P∩G| / ( |P∩G| + α·|P\G| + β·|G\P| )
```

softmax 输出下的训练形式（论文式(3)定义指数 T 并要求 cost minimization；最小化其补 1−T 是通行推断，与主流实现一致）：

```
T(α,β) = Σᵢ p0ᵢ·g0ᵢ / ( Σᵢ p0ᵢ·g0ᵢ + α·Σᵢ p0ᵢ·g1ᵢ + β·Σᵢ p1ᵢ·g0ᵢ )
```

其中 p0ᵢ 为体素 i 属病灶的概率，g0ᵢ/g1ᵢ 为对应真值指示；**α 权重假阳 FP（|P\G|），β 权重假阴 FN（|G\P|）**——这是最常被弄反的一点。

## 适用

- 分割（论文场景：3D FCN 病灶分割）；对二类、前景占比极小（1:500 以上）的不平衡数据设计。
- 漏检代价高于误报的医学应用（病灶、微小心结构），需要在 precision-recall 之间显式定偏好的场景。
- 多类分割可对每个前景通道独立计算再平均（参考实现即此做法）。

## 行为特征

- 与 Dice loss 同族、同为区域级目标（不看 TN），收敛动力学相似；α=β=0.5 时严格退化为 soft Dice loss。
- β↑ → 敏感度单调升、特异度微降（论文：49.85%→65.57% / 99.93%→99.87%）；是显式的 precision-recall 调节旋钮，而非只靠阈值后处理。
- 最优 β 落在中间：论文 β=0.7 综合最优，β≥0.8 后 DSC 反而明显下滑（48.57 / 46.42）——过压召回会伤精确度。
- 观察指标：DSC、敏感度、F2、PR 曲线下面积（论文认为 APR 是高度偏斜数据上最可靠的单一指标）；Dice loss 训练时应同步盯 DSC↔敏感度，Tversky 训练时确认 β 的方向效应确实出现（敏感度应系统性高于 Dice 基线）。

## 调参经验

- 论文沿 α+β=1 一维网格搜索 (0.5,0.5)→(0.1,0.9)，最优 **(α,β)=(0.3,0.7)**；建议流程：先跑 Dice（0.5,0.5）基线，漏检多则加大 β（先试 0.7），误报失控再回调 α。
- β 不宜顶格：论文 0.8/0.9 时 DSC 反降至 48.57/46.42，FN 权重过大以牺牲大量精确度为代价。
- 平滑项：分母加小 eps（如 1e-7）防全零 0/0 即可；不要照搬 hard 指标的 smooth=1，小目标时会显著抬高指数、弱化梯度。
- 2×RTX 4090（约 23 GB/卡）小显存预算下建议 AMP 训练，统计量 TP/FP/FN 的累加放 fp32（`sum` 前转 float 或确保 reduction 在 fp32 进行），避免半精度下软计数精度损失。
- 与 CE 组合（CE+Tversky）可弥补纯 TI 类损失不看 TN、早期训练缺塑形信号的短板；纯 Tversky 在极不平衡数据上早期可能方向不稳。
- focal Tversky `(1−TI)^γ` 不是本论文内容（γ 是后续工作，如 Abraham & Khan 2018 引入），需要在难样本上加权时再去考虑。

## 坑

- **α/β 语义极易弄反**：论文 α↔FP、β↔FN，但部分博客/开源库写法相反。接手他人实现先做方向对拍（固定一个漏检预测，β 大的 loss 必须更大——参考实现自测第 3 项）。
- 过压召回（β 接近 1）后 DSC 反降：敏感度上升的收益被精确度损失吃掉，需同时监控 DSC/APR，不能只看敏感度。
- α+β=1 并非强制约束（Tanimoto 为 α=β=1），但论文只搜索了 α+β=1 的一维网格；两维都放开的调参无论文依据，慎做。
- 聚合口径：论文式(3)写成对体素的整体求和，通行训练实现按 (样本,通道) 各算一个指数再平均——两者数值不等（mean(比值)≠比值(总和)），复现/对比实验时口径要一致。
- 硬化阈值仍需调：论文用 0.5 二值化；偏向召回训练后，最优点常移向更低阈值，评价时应配合阈值扫描。
