# 半监督双向复制粘贴（bcp-semi-supervised-copy-paste）

类别：`[augmentation]`

## 论文支撑（统一四问）

- **哪篇论文用了它**：Bai, Chen, Li, Shen, Wang，**BCP**（Bidirectional Copy-Paste），CVPR 2023，[arXiv:2305.00673](https://arxiv.org/abs/2305.00673)。
  **目的**：半监督医学图像分割中，Mean-Teacher 框架的已标注图与未标注图分布不一致，一致性正则在两堆图像上分别施加会导致特征脱节；BCP 在框架内把已标注图与未标注图**互相贴 patch（双向 copy-paste）**，弥合两侧分布差。
  **效果**：ACDC（心脏 MRI 分割）5% 标注 +21% Dice。
  **结论**：对本仓库"几十例标注 + 可补无标注"的场景是极强路线。

## 机制与动机

半监督分割的典型困境是"标注图一小撮、未标注图一大堆"：Mean-Teacher 类一致性正则让教师与学生对同一输入的扰动预测保持一致，但若标注图与未标注图从不共享输入，未标注图上学到的一致性特征与标注图监督的特征是两套分布。BCP 的解法是在训练框架内做**双向**复制粘贴：一个方向把已标注图的 patch 贴入未标注图，另一个方向把未标注图的 patch 贴入已标注图——两个方向各产生一份"你中有我"的混合图参与师生一致性训练，使一致性正则的两侧见到同一混合分布，从而对齐标注域与未标注域。

注意它与监督场景复制粘贴（[lesion-copy-paste.md](lesion-copy-paste.md)）的分工：BCP 的贴入物不要求是病灶、也不负责造真阳性标签，它解决的是**半监督训练的分布对齐**问题，而不是"正样本模式不够多"的问题。

## 适用（什么时候用）

- **场景**：有几十例标注、且能补一批**同模态/同采集协议**的无标注数据时优先考虑——这正是本仓库服务的小数据医疗影像场景。
- **模态/任务**：核实证据在 ACDC 心脏 MRI 分割；方法框架任务无关，分割类任务皆可尝试。
- **训练范式**：要求接受 Mean-Teacher 式半监督训练框架（师生网络 + 一致性正则），不是往现成监督流水里加一个 transform。
- **不适用**：没有无标注数据可用；或无标注数据与标注图模态/协议差异过大（此时粘贴混合反而引入跨域噪声）。

## 预期收益

- ACDC 5% 标注 +21% Dice（CVPR 2023，核实口径）。
- 对应到本仓库预算（几十例标注 + 2×RTX 4090 单卡 23GB），这是"不新标数据也能涨"的少数已验证路线之一：收益来自无标注数据，而不是更多标注。

## 风险与坑

- **它是框架级改动**：Mean-Teacher + 双向粘贴 + 一致性损失，引入教师网络、一致性损失权重等新超参与新监控项，训练状态诊断（曲线解读）比纯监督复杂；不要按"加一个增强算子"的工作量预估。
- **收益依赖无标注数据**：无标注数据的量、质量与同分布性直接决定收益上限；拿不到同分布无标注数据时退化为普通复制粘贴，增益失去依据。
- **同卡 batch 同时装标注图与未标注图**（双向混合的输入需求），同显存下 batch 规模比纯监督小——本仓库 23GB 预算下需在 patch 尺寸与 batch 之间权衡。
- **粘贴本身的通用风险仍然存在**：边缘过渡、贴入位置合理性等见 [lesion-copy-paste.md](lesion-copy-paste.md) 的"风险与坑"栏。
- **与病灶感知复制粘贴不要混为一谈**：BCP 面向分布对齐（半监督），CarveMix/TumorCP 面向造真阳性（监督增强）；两者可视为"贴"这个动作在两个不同问题上的应用。

## 参数与经验值

- 事实包未收录 BCP 的具体超参（粘贴比例、区域选择策略、一致性损失权重等）；实现时以论文正文与官方代码为准，不在卡内虚构数值。
- 场景锚点：ACDC 5% 标注是**极低标注率**设定——本仓库"几十例标注"的量级与之同型，收益预期可参照但需在自己的数据上验证。
