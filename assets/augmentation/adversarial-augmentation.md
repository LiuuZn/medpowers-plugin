# 对抗式增强（adversarial-augmentation，AdvChain）

类别：`[augmentation]`

## 论文支撑（统一四问）

- **哪篇论文用了它**：Chen, Qin, Ouyang, …, Rueckert，"Realistic Adversarial Data Augmentation for MR Image Segmentation"，MICCAI 2020（LNCS 12261 pp.667–677，[DOI 10.1007/978-3-030-59710-8_65](https://doi.org/10.1007/978-3-030-59710-8_65)）；期刊扩展 **AdvChain**，Medical Image Analysis 2022（[DOI 10.1016/j.media.2022.102597](https://doi.org/10.1016/j.media.2022.102597)；[arXiv:2108.03429](https://arxiv.org/abs/2108.03429)）。
- **目的**：不再从固定分布随机施增强，而是**对抗式搜索难样本方向**——在可微变换空间里主动生成"恰好让分割网犯错"的样本，与分割网联合优化。
- **效果**（期刊版，低标注量）：心脏 ACDC N=1 平均 Dice 0.4731 vs 标准训练 0.3882；半监督 N=3 0.8083 vs VAT 0.7866；前列腺半监督 0.6492 vs 0.6126。
- **结论**：极低标注量下增益显著；方法面向**域偏移鲁棒性**而非域内精度；代价是训练开销约普通训练 2–3 倍（对抗内循环）；边界为 2D MR 序列。

## 机制与动机

普通增强从固定随机分布采样——大多数增强样本是"简单"的，网络在平庸扰动上学不到决策边界外。本方法把增强参数化为**四种可微变换的随机链**：噪声、B 样条偏置场、仿射、微分同胚形变；每个 batch 沿"让当前分割损失变大"的方向（对抗梯度）在变换参数空间里制造难样本，再让分割网消化它——min-max 博弈：扰动一方制造困难、分割一方吸收困难。会议版聚焦对抗偏置场（即 AdvBias）；期刊版扩成完整四组件链。动机：小标注下网络对采集变异（偏置场、噪声、形变）极敏感，把变异集中打在最脆弱处，等价于在最需要的方向上扩充数据。

## 适用（什么时候用）

- **模态**：MRI（ACDC 心脏、前列腺 MR 验证）；偏置场/噪声组件有 MRI 采集对应物，CT 侧灰度扰动的对应做法见相关卡。
- **2D/3D**：**2D MR 序列**（论文边界）；3D 直接套用未验证。
- **数据量级**：为极低标注设计——N=1/N=3 收益最大；标注充足时标准增强已够，性价比下降。
- **任务特征**：域偏移鲁棒性优先（跨中心/跨序列）；纯域内精度提升非其卖点。

## 预期收益

- ACDC N=1（单例标注）：0.4731 vs 标准训练 0.3882（+8.5 点）——低标注区间的代表性数字。
- 半监督 ACDC N=3：0.8083 vs VAT 0.7866；前列腺半监督 0.6492 vs 0.6126。
- 标注充足时相对强基线的增益：无单独消融，论文未给。

## 风险与坑

- **训练开销 2–3 倍**：对抗内循环每步额外反传扰动梯度；本仓库 2×4090 上属长训练，按 lease 协议规划。
- **域内精度不是卖点**：方法定位域偏移鲁棒性；域内任务与强基线（nnU-Net 默认）对比可能无优势。
- **扰动可能越出"真实"边界**：论文以 realistic 为名约束——四个变换族（噪声/偏置场/仿射/微分同胚形变）本身是物理先验，但扰动幅度不设限仍会造出医学上不现实的样本。
- **min-max 不稳定**：对抗训练通病——扰动步长过大训练震荡、过小退化为随机增强；具体超参以论文与官方实现为准。
- **误称 DADA**：本方法文中**未出现 "DADA" 缩写**（常被误称）；DADA 是通用 CV 的可微增强搜索（见自动增强搜索卡注记），两回事。
- **与 AdvBias 的关系**：会议版的对抗偏置场即 AdvBias，是本条变换链的偏置场特例（单体卡见相关卡）。

## 参数与经验值

- 变换链四组件：噪声、B 样条偏置场、仿射、微分同胚形变（随机链组合，参数可微、可对抗更新）。
- 验证设置：ACDC 心脏 N=1 与半监督 N=3、前列腺半监督，均为 2D MR。
- 开销量级：约普通训练 2–3 倍。
- 扰动步长/内循环迭代数等超参未在核实材料中给出——以论文与官方实现为准。
