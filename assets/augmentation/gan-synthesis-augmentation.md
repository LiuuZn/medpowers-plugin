# GAN 合成增强（gan-synthesis-augmentation）

类别：`[augmentation]`

## 论文支撑（统一四问）

### ① Frid-Adar 等，Neurocomputing 2018（[arXiv:1803.01229](https://arxiv.org/abs/1803.01229)）

- **哪篇论文用了它**：Frid-Adar 等，DCGAN 合成增强，2018。
- **目的**：只有 182 个 CT 肝病灶 ROI（囊肿/转移/血管瘤三分类），训 DCGAN 合成额外样本，叠加到经典增强之上扩充训练集。
- **效果**：敏感性 78.6%→85.7%（+7.1 点）、特异性 88.4%→92.4%（+4.0 点）。
- **结论**：几百张 2D patch 级样本即可训出有效的 GAN 增强；3D 体数据不直接适用。

### ② GenSeg（Zhang, Jindal, …, Xie），Nature Communications 2025, 16:6486

- **哪篇论文用了它**：GenSeg，2025。
- **目的**：条件 GAN（Pix2Pix 式掩码→图像）按标签图合成配对样本，保证合成样本自带精确标注；生成器架构可搜索——三层多级优化用验证集分割精度反向指导。
- **效果**：19 个数据集（含 MSD 海马/肝脏 3D）：小样本 Dice 绝对 +10.9~+20.6%，等效标注量减少 8–20 倍；对 nnU-Net 域内 +1–7%、OOD +5–16%。
- **结论**：掩码条件化是医疗 GAN 合成的有效形态；但管线复杂、复现成本高；其消融中扩散生成器（BBDM）质量最高而算力代价大——预示扩散路线（见相关卡）。

## 机制与动机

生成对抗网络从训练分布"多造样本"：生成器合成图像、判别器分辨真假，对抗训练把生成分布逼向真实分布。医疗场景的标准形态是**掩码条件化**（GenSeg）：以标签图为条件合成对应图像，合成样本自带精确标注，绕开"合成图像没有标注"的死结。与经典增强（旋转/翻转/形变等对既有样本的变换）相比，GAN 合成产出的是**新的外观/纹理/病灶形态**，补的是经典增强覆盖不到的表型多样性。动机：小数据下真实分布采样不足、网络见过少，合成样本把有效训练集做大。

## 适用（什么时候用）

- **模态**：CT/MRI 皆可（肝病灶 CT、海马 MRI 等均有验证）。
- **2D/3D**：**以 2D patch/切片级为主**——共识边界：GAN 高分辨率/3D 体级生成不稳定、模式坍塌；小数据下 2D patch 级可行、3D 体级困难（GenSeg 虽含 3D 数据集，仍以 2D 为主）。
- **数据量级**：2D 分类场景几百张即可起步（Frid-Adar 用 182 个 ROI）；分割场景需配对掩码-图像数据训条件 GAN。
- **任务特征**：类不平衡、病灶表型多样性不足、标注极度稀缺时考虑；3D 体数据与跨域泛化优先选不训生成器的合成路线（见相关卡）。

## 预期收益

- 2D 分类（Frid-Adar）：敏感性 +7.1 点、特异性 +4.0 点（182 ROI 量级取得）。
- 分割（GenSeg）：小样本 Dice 绝对 +10.9~+20.6%；等效标注量减少 8–20 倍；nnU-Net 域内 +1–7%、OOD +5–16%（19 数据集）。

## 风险与坑

- **模式坍塌**：GAN 的经典失效——生成器收敛到少数几种输出，合成样本多样性反而不足；小数据下判别器过强/过弱都易触发。
- **高分辨率/3D 生成不稳定**：体级 GAN 训练代价高、质量差，正是"2D patch 级可行、3D 体级困难"共识的来源。
- **合成标注质量是隐雷**：无条件合成没有标注可用；掩码条件化要求掩码-图像对齐过关，否则网络学到错位映射。
- **管线复杂、复现成本高**（GenSeg）：条件 GAN + 三层多级架构搜索，工程量大——先吸收其结论（掩码条件化最有效），再评估是否值得复现全管线。
- **扩散生成器已在消融中胜出**（GenSeg：BBDM 质量最高但算力代价大）：新项目走生成合成路线时，应把扩散方案一并纳入比较。

## 参数与经验值

- 分类起步门槛（Frid-Adar）：182 个 2D ROI；架构 DCGAN；叠加在经典增强之上而非替代。
- 分割配置（GenSeg）：条件 GAN（Pix2Pix 式掩码→图像）；生成器架构三层多级优化，指导信号为验证集分割精度；19 数据集含 MSD 海马/肝脏 3D。
- 两文具体学习率/批大小等训练超参未在核实材料中给出——起步照官方/论文设置。
