# assets/models — 任务无关的模型资产

收录**任务无关**的网络架构及其论文。一条 = 一个模型卡（一个 md 文件），命名 `<family>-<variant>.md`（如 `unet3-2d.md`）。

> 条目含代码（`<slug>.py`）时，代码须遵循统一代码规范 [../CODE_STYLE.md](../CODE_STYLE.md)（依赖、自包含、文件头、类型标注、数值稳定、自测块、与资产卡同名配对）。

## 模型卡字段

- **论文支撑（必填）**：按文末统一四问格式，简体中文写明
- **核心机制**：一句话说清它凭什么有效
- **量级**：参数量 / 显存 / 计算量级（按 2×4090 23GB 预算标注可行性）
- **适用**：数据量级、2D/3D、目标结构尺度（大器官 vs 细小结构）
- **短板与不适用场景**
- **对比基准与选型建议**：证据来自与什么基线的对比（注明同数据/同配方同预算）、什么条件下表现更好、什么场景值得尝试、什么场景明确不值得
- **经验备注**：初始化、变体、实现参考（如 `/ssd/lx/net_arch/arch_Unet3_2D.py`）
- **实验反链**：相关 `EXP-*` 记录

## 收录边界

只写任务无关的机制与经验；具体数据集/器官上的表现写进实验记录，再回链。

## 论文支撑统一四问（每项一两句话，写简单）

- **哪篇论文用了它**：团队/作者 + 简称 + 年份（附链接）
- **目的**：论文用它来解决什么问题
- **效果**：取得了什么提升（有数字写数字）
- **结论**：论文下的结论 / 适用边界

无论文支撑的架构不作为正式条目，先记入"补录起点"。
