# unet3d — 3D U-Net（体素分割基石，U-Net 的 3D 直接扩展）

**论文所读版本**：arXiv:1606.06650（2016-06-21 提交版，MICCAI 2016 会议论文的 arXiv 副本）；已通读 arXiv 摘要页、ar5iv HTML 全文与 arXiv PDF 全文（正文含表 1–3 数字均从 PDF 原文核对）。

## 论文支撑（统一四问）

- **哪篇论文用了它**：Ö. Çiçek 等（弗赖堡大学），《3D U-Net: Learning Dense Volumetric Segmentation from Sparse Annotation》，MICCAI 2016。https://arxiv.org/abs/1606.06650
- **目的**：在只有稀疏标注（每个体积人工标注 19–33 张正交切片，三样本合计 77 张）的条件下端到端训练 3D 分割网络——半自动场景把用户少量标注"致密化"为完整 3D 分割，全自动场景在稀疏标注训练集上训练后分割新体积。
- **效果**：半自动 3 折交叉验证平均 IoU 0.863（带 BN；不带 BN 0.842；同数据 2D U-Net 仅 0.796，表 1）；全自动跨体积测试平均 IoU 0.704（带 BN）/ 0.723（不带 BN），2D U-Net 仅 0.547（表 3）；每个正交方向只标 1 张切片（约 2.5% 体素）IoU 0.331–0.483，标 (5,5,3) 张（约 8.9% 体素）三样本 IoU 0.849–0.872（0.856/0.849/0.872，表 2）。
- **结论**：网络可从零端到端训练、无需预训练；把未标注体素的损失权重置 0 即可从稀疏标注学到稠密 3D 分割；3D 上下文相对 2D 提升显著（全自动 0.704 对 0.547）。作者预期可推广到其他生物医学体积分割任务。

## 核心机制

编码-解码对称的 3D 全卷积网络：分析路每级两个 3×3×3 卷积 + 2×2×2 最大池化，通道逐级翻倍（避免瓶颈）；合成路每级 2×2×2 转置卷积上采样 + 两个 3×3×3 卷积，等分辨率 shortcut 把高分辨率特征直接送回解码路——每个输出体素同时"看到"大上下文与高分辨率细节（论文 132×132×116 输入的感受野约 155×155×180 µm³）。配合加权 softmax 交叉熵（未标注体素权重 0），稀疏标注即可监督稠密输出。

## 量级

- 论文正文给出总参数量 **19,069,955**（原文数字）；逐级通道数仅在图 2 标注（正文只写"池化前翻倍"、分析/合成路各 4 个分辨率级），常见复现按 32→64→128→256 起步。注意：按 32 起步复现（参考实现显式取 in=3、3 类、channels=(32,64,128,256)、valid+BN，即自测 PASS 5 的论文风格配置）实算 5,604,323——构造函数缺省（in=1、2 类）为 5,602,562——与正文总数存在出入，以正文 19,069,955 记录论文网络规模，复现配置以各自实算为准。
- 论文几何（valid 卷积）输入 132×132×116 → 输出 44×44×28，整卷需滑窗拼接。
- 2×4090 23GB 预算：该谱系现代小配置（nnU-Net 风格，5–6 级、padded 卷积、patch 96–128³）batch 1–2 + AMP 单卡可训，是 3D 侧的主力骨干量级；更深/更大 patch 需降 batch 或开梯度检查点。参考实现自带小测试配置 channels=(4,8,16) 共 21,527 参数，CPU 几秒可跑通自测。

## 适用

- 3D 体数据（CT/MRI/共聚焦等）分割，目标有明确 3D 上下文（大器官、管状/腔体结构）。
- 标注稀缺的场景：半自动下每方向几张切片（(5,5,3) 张，约 8.9% 体素）三样本 IoU 0.849–0.872、3 折 CV 平均 0.863；全自动实验仅用 3 个体积（2 训 1 测、3 种轮换组合）即展示跨体积泛化——论文同时指出典型全自动场景样本量更大，稀疏标注可摊到更多样本。
- patch-based 设计可处理任意大体积（论文 seamless tiling）；对小数据集泛化好（增广 + 多尺度上下文）。

## 短板与不适用场景

- valid 卷积输出远小于输入（132×132×116 → 44×44×28），滑窗推理需 overlap、有边界效应；现代实现改 padded 卷积，但那已不是论文几何。
- 各向同性 2×2×2 池化对各向异性体素（如 CT z 向层厚大）不当，细小/扁平结构会被过早池化掉——细小结构分割考虑 2.5D 或改各向异性池化（nnU-Net 做法）。
- batch 通常只能 1–2：BN 统计不稳（论文为此在测试时也用当前批统计；现代实践多换 InstanceNorm，如本仓库 net_arch 的 2D 变体）。
- 3D 卷积显存开销大，深级通道翻倍后特征图显存主导预算；扩展感受野靠深度，过深则底部特征图过小、小目标信息丢失。

## 经验备注

- 初始化：论文未提及任何初始化方案（保留框架默认即可）；现代谱系 nnU-Net 用 He 初始化 + LeakyReLU，非论文内容。
- 现代代表实现：nnU-Net 的 `PlainConvUNet`（totalsegmentator 在用的 3D 骨干，本机 `/ssd/lx/totalsegmentator/.venv/lib/python3.11/site-packages/dynamic_network_architectures/architectures/unet.py:21`）——padded 卷积、可配 norm/深监督，即本架构谱系。
- 2D 同谱系变体见 `/ssd/lx/net_arch/arch_Unet3_2D.py`（InstanceNorm + LeakyReLU + 深监督，池化层数按 spacing/patch 自适应）。
- 参考实现：`assets/models/unet3d.py`。默认完全按论文（valid 卷积、BN 前置于每个 ReLU、BN 测试时用批统计）；`padded=True`、`bn_use_batch_stats_at_eval=False` 切换到现代行为，差异处均以论文为准注明。
- 数据增广经验（论文 3.2 节）：旋转/缩放/灰值 + 间距 32 体素网格上 std=4 正态随机向量经 B 样条插值的平滑弹性形变，在线生成；这是小数据下泛化的关键之一。
