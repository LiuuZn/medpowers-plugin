# 方法论 ④：标注上限诊断（模型平台期先测标注，再调模型）

**适用时机**：模型在多轮「一次只改一族」调优后收敛到平台、且多方案（不同范式/特征/集成）成绩互相矛盾或高度接近时，**先怀疑标注，再怀疑模型**。

## 原理

监督学习的 strict 指标上限由「标注一致性」决定：若同一结构在不同样本上被标注的判定规则不可复现（人眼主观、规则含糊、跨标注者漂移），任何模型的 strict 命中率都会被钉在标注噪声水平附近。此时继续加大模型/特征/集成是无效投入。

## 诊断四步（从便宜到贵）

### ① 神谕探针（oracle probe）

把「锚点/候选位置」误差从评测中消除：给局部判别器喂**以真值为中心**的窗（而非预测锚点）。若 oracle 条件下精度仍显著低于目标 → 判别所需信息不在输入里（标注模糊或特征缺失），换特征/加数据大概率无效。

- 判读：oracle 精度 ≈ 目标 → 标注问题；oracle 高但锚点条件下低 → 定位/窗口放置问题，模型侧仍有救。

### ② 特征排名检验（rank test）

对「标注规则假设」涉及的每条可计算曲线（如逐片面积/强度剖面）：取标注片在其邻域窗（±k 片，k 覆盖一个结构单元）内的**排名分布**。

- 判读：排名接近均匀 → 该特征与标注无关（注意先排除 z 方向翻转、ROI 污染、阈值相位反转三种测量错误，见下）；
- 排名集中在 0 但 argmax 命中率低 → 存在平台/平票，规则成立但需「平台中心」解码与人眼仲裁。

### ③ 审片图（review sheet）

把候选切片按绝对索引编号渲染成拼条 PNG，请规则知晓者直接指认。这是校准「人眼所见」与「可计算特征」差距的最短路径——一次人工指认可兑换成具体的特征/ROI 修正。

### ④ 争议清单（disputed list）

模型概率呈双峰/平台（前两名差距小于阈值）的样本批量导出+可视化，交人工仲裁。仲裁结果用于：(a) 修正标注后重训；(b) 统计「标注不可判定样本」占比，即为 strict 指标的实测上限证据。

## 常见测量陷阱（下结论前逐条排除）

- **z 方向翻转**：标注索引与体数据栅格方向相反（先做翻转假设对照检验）；
- **坐标系不一致**：NRRD 头声明 LPS/RAS 与标注世界坐标不符（影像普遍为 LPS）；
- **阈值相位反转**：高阈值只抓皮质/致密结构，低阈值才含松质骨——同一曲线在不同阈值下相位可能相反；
- **厚层部分容积**：厚层厚下「间隙层」切片混入相邻终板皮质，简单计数会出现与直觉相反的峰；
- **ROI 污染**：伴行结构（如肋骨、走行平行于目标轴的器官）混入统计框——用沿目标轴的累加投影分离目标柱。

配套工具：`skills/data-mgmt/label_audit.py`（柱内面积剖面 / 排名检验 / 审片图），用法见该脚本 docstring 与 data-mgmt SKILL.md。

## 输出契约

- 标注一致性结论：可复现规则（附实测覆盖率）/ 部分可复现（平台+人眼仲裁部分）/ 不可复现；
- strict 指标实测上限估计；仲裁样本清单（如有）；
- 与 EXP 记录互链。若无以上证据，不得做出「标注已到上限、放弃模型侧」的结论。
