# 方法论 ②：训练状态诊断

拿到训练结果后，判断"当前训练处于什么状态"。这是整个回路的核心：**结合不同损失函数与目标函数（含不可导指标）的行为差异来交叉判断**，而不是只看单一 loss 曲线。

## 输入信号

- train/val 的总损失与各损失分量曲线（随 epoch）
- 不可导指标曲线（ Dice、HD95 等，train + val）
- 曲线特征：收敛速度、是否平台、震荡幅度、train-val 拐点与间距
- （若有）梯度范数、权重统计、各样本/各区域误差分布

## 状态分类（基线框架）

| 状态 | 典型信号 |
| --- | --- |
| 欠拟合 | train/train 指标双双低位，仍在线性下降 |
| 过拟合 | train 持续降、val 拐头升，间距随 epoch 扩大 |
| lr 过高 | loss 早期爆/剧烈震荡，指标抖动 |
| lr 过低 | 收敛极慢、长平台、loss 下降幅度远低于预期 |
| 损失分量失衡 | 某分量主导总 loss，其余近乎不降 |
| 指标-目标背离 | 可导 loss 持续下降但不可导指标不动甚至变差 |
| 收敛平台 | 各曲线均走平，未达精度要求 |

## 核心手段：多目标交叉判断

- 同一训练中**多个损失分量是否同向下降**：分歧 → 损失失衡或加权不当
- **可导目标 vs 不可导指标是否一致**：背离 → 优化目标没有代理好真实指标（换/组合 loss，对照 `assets/objectives/`）
- 必要时用小规模对照轮次：仅换损失/目标（模型、数据不动）观察行为差异，据此区分"模型容量问题"还是"优化目标问题"

## 输出契约

输出：状态判断（可多选）+ 每项判断的证据（引用曲线特征）+ 置信度（高/中/低）。写入实验记录"诊断"栏，作为方法论③的输入。
