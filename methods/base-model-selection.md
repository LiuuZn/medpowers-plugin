# 方法论 ①：基础模型选择

任务进入训练前的第一步：从 `assets/models/` 中选出基础模型。

## 输入：任务画像（决策前必须先填齐）

- 模态与维度：CT/MRI、2D 切片还是 3D 体数据
- 数据量级：训练样本数（百 / 千 / 万级）——小数据优先小模型
- 目标结构：数量、尺度（大器官 vs 细小结构 vs 多尺度混合）、前景占比
- 精度要求：主导评价指标是什么（决定模型容量下限）
- 预算：2×4090（Ada sm_89，每卡 23GB）下的 batch / 输入尺寸约束，优先 AMP + bf16；fp16/FP8/TF32 的适用条件见 [precision-policy.md](precision-policy.md)

## 决策顺序

1. 数据量级 → 先划定候选模型容量区间（防欠拟合/过拟合两头）
2. 维度与结构尺度 → 在区间内筛架构族（2D/3D、感受野、多尺度能力）
3. 显存与吞吐 → 排除装不下/训不动的组合
4. 对照 `assets/models/` 各模型卡的"适用/短板"字段做最终比对

## 输出契约

给出 **1 个主选 + 1 个备选**，逐条引用任务画像说明理由；结论写入当轮实验记录的"基础模型"栏。备选用于主选训练状态诊断失败时的快速切换。
